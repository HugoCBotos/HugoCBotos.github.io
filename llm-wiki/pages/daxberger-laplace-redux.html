Laplace Redux

Laplace Redux — Effortless Bayesian Deep Learning — Daxberger, Kristiadi, Immer, Eschenhagen, Bauer, Hennig (NeurIPS 2021)

📄 Paper: arXiv:2106.14806
📁 Source: 2021_Daxberger_Laplace_Redux.pdf
🛠️ Code: github.com/aleximmer/Laplace
🎯 Core Idea

After standard MAP training, approximate the posterior as a Gaussian centered at the MAP estimate using a second-order Taylor expansion of the log-joint. Modern Hessian approximations (Kronecker-factored, diagonal) make this scalable to modern architectures.

Mathematical Formulation

The Laplace Approximation

Given a MAP estimate wMAP, the log-posterior is approximated by a second-order Taylor expansion:

$$\log p(w \mid D) \approx \log p(w_{\text{MAP}} \mid D) - \frac{1}{2}(w - w_{\text{MAP}})^T H\,(w - w_{\text{MAP}})$$

where $H = \nabla^2 \log p(w \mid D)$ is the Hessian of the negative log-joint at the MAP estimate. This implies a Gaussian posterior:

$$p(w \mid D) \approx \mathcal{N}(w;\, w_{\text{MAP}}, H^{-1})$$

Hessian Approximations for Scalability

Full Hessian is O(D²) where D is the number of parameters — infeasible for modern nets. Daxberger et al. systematically compare approximations:

ApproximationMemoryQualityNotes
Full (via GGN)O(D²)BestOnly for small models
Kronecker-Factored (K-FAC)O(L·(d_in² + d_out²))Very GoodBest practical choice for moderate nets
DiagonalO(D)ModerateIgnores off-diagonal correlations
Last-LayerO(L_out²)GoodOnly last layer — surprisingly effective

Why It Matters for Practitioners

  • Post-hoc: Applied after standard training — no need to modify training.
  • Last-layer Laplace is especially compelling: treat the network as a feature extractor, then apply Laplace only to the final linear layer. This is cheap and often gives excellent uncertainty estimates.
  • Compatible with any pretrained model — just add Laplace on top.

Using the Library

from laplace import Laplace

model = trained_model  # any PyTorch model

# Fit Laplace approximation
la = Laplace(model, 'classification',
             subset_of_weights='last_layer',
             hessian_structure='kron')
la.fit(train_loader)

# Predict with uncertainty
pred = la(x)
uncertainty = la.predictive_samples(x).var(dim=0)

Pros & Cons

✅ Advantages❌ Disadvantages
Post-hoc — no training changes needed Local approximation (Gaussian around mode) — may miss multi-modality
Works with any pretrained model Full Hessian is impractical at scale
Last-layer version is extremely efficient Posterior quality depends on the quality of the MAP estimate
Mature, well-documented Python library available Not suitable for very deep weight-space posteriors (last-layer recommended)
