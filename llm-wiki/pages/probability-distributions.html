3. Probability Distributions (The Minimal Toolkit)

🎯 In one sentence

A probability distribution tells you how likely each possible value of a variable is. Instead of "the weight is 0.5", we say "the weight follows a Gaussian distribution centered at 0.5 with spread 0.1".

This page covers the absolute minimum probability you need to understand BNNs. If you already know what a Gaussian (normal) distribution is, you can skim this.

Random Variables

A random variable is a variable whose value is uncertain. We denote it with a capital letter (X) and its possible values with lowercase (x).

There are two kinds:

  • Discrete: takes values from a countable set (e.g., coin flip: heads or tails)
  • Continuous: takes values from ℝ (e.g., the speed of a particle)

In BNNs, weights are continuous random variables. They can be any real number.

Probability Density Function (PDF)

For a continuous random variable, the PDF p(x) tells us the relative likelihood of different values. The probability that X lies in an interval [a, b] is:

Probability from PDF
$$P(a \le X \le b) = \int_a^b p(x)\,dx$$

The PDF must satisfy:

  • $p(x) \ge 0$ for all $x$ (probabilities can't be negative)
  • $\int_{-\infty}^{\infty} p(x)\,dx = 1$ (total probability = 1)

Expectation (Average)

The expected value (mean, average) of a random variable is its "center of mass":

Expectation (for continuous variables)
$$\mathbb{E}[X] = \int x\,p(x)\,dx$$
(For discrete variables, replace the integral with a sum: $\mathbb{E}[X] = \sum x\,p(x)$.)

Think of this as: take each possible value x, weight it by how likely it is, and sum them up. It's the average value you'd get if you sampled infinitely many times.

Expectation is linear: $\mathbb{E}[aX + b] = a\,\mathbb{E}[X] + b$.

Variance (Spread)

The variance measures how spread out the distribution is — how much uncertainty there is:

Variance
$$\operatorname{Var}[X] = \mathbb{E}[(X - \mathbb{E}[X])^2] = \mathbb{E}[X^2] - \mathbb{E}[X]^2$$

The standard deviation is σ = √Var[X], which has the same units as X and is easier to interpret.

The Gaussian (Normal) Distribution

This is the most important distribution for BNNs. Almost all methods assume (at least approximately) that weights follow a Gaussian distribution.

Gaussian PDF
$$p(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2\right)$$

Where:

  • $\mu$ (mean) controls where the bell is centered
  • $\sigma$ (standard deviation) controls how wide it is

The formula says: the probability density at x decays exponentially with the squared distance from the mean, scaled by how wide the distribution is. The 1/(σ√(2π)) is just a normalization constant to make the total area = 1.

Parameters:

  • μ (mean): the center of the bell curve
  • σ (standard deviation): the width of the bell curve

We write X ~ N(μ, σ²) to say "X follows a Gaussian with mean μ and variance σ²".

📐 Key facts:
  • About 68% of the probability mass lies within μ ± σ
  • About 95% lies within μ ± 2σ
  • The Gaussian is the "maximum entropy" distribution for a given mean and variance — it's the most uninformative (safest) choice when we only know the first two moments.

Multivariate Gaussian

In BNNs, we often have many weights that are correlated — knowing one weight's value tells us something about another. The multivariate Gaussian captures this:

Multivariate Gaussian
p(x) = 1 / ( (2π)d/2 |Σ|1/2 ) · exp( −½ (x − μ)T Σ−1 (x − μ) )

Where:

  • μ ∈ ℝd is the mean vector
  • Σ ∈ ℝd × d is the covariance matrix
  • Σij = Cov[Xi, Xj] measures how Xi and Xj co-vary

The covariance matrix is huge (d × d for d weights, which could be millions). Most BNN methods make simplifying assumptions about Σ to stay computationally feasible.

Sampling

Sampling means generating random values from a distribution. In PyTorch, this is easy: 

import torch

# Sample from a Gaussian: N(5, 3²)
samples = torch.normal(mean=5.0, std=3.0, size=(1000,))
print(samples.mean())   # ≈ 5.0
print(samples.std())    # ≈ 3.0

# Sample from a multivariate Gaussian
mean = torch.tensor([0.0, 1.0])
cov  = torch.tensor([[1.0, 0.5], [0.5, 2.0]])  # covariance matrix
samples = torch.distributions.MultivariateNormal(mean, cov).sample((500,))

This ability to sample is crucial for BNNs — we approximate the posterior by drawing samples from it and averaging the predictions.
