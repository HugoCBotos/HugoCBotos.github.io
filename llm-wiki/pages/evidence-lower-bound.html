6. The Evidence Lower Bound (ELBO)

🎯 In one sentence

The ELBO is the objective function we optimize in variational inference. Instead of maximizing the intractable posterior, we maximize a lower bound on the log-evidence. It naturally decomposes into "fit the data" minus "stay close to the prior".

This is the bridge between Bayesian inference (page 2) and practical optimization (page 7). If you understand the ELBO, you understand what variational BNNs are actually doing.

The Problem: We Can't Compute the Posterior

Recall Bayes' theorem:

$$p(w \mid D) = \frac{p(D \mid w) \, p(w)}{p(D)}$$

The denominator $p(D) = \int p(D \mid w) \, p(w) \, dw$ involves integrating over all possible weights — impossible for a neural network with millions of parameters.

Idea: Instead of computing the posterior exactly, we choose a simple family of distributions $Q$ (e.g., Gaussians) and find the $q \in Q$ that best approximates the true posterior.

Deriving the ELBO

We want to minimize $\operatorname{KL}[q(w) \parallel p(w \mid D)]$. Let's expand it step by step:

Step 1: Write the definition of KL
$$\operatorname{KL}[q \parallel p(w \mid D)] = \int q(w) \log\frac{q(w)}{p(w \mid D)}\,dw$$ $$= \mathbb{E}_{q}[\log q(w)] - \mathbb{E}_{q}[\log p(w \mid D)]$$
Step 2: Replace $p(w \mid D)$ using Bayes' theorem
$$\text{Recall: } p(w \mid D) = \frac{p(D \mid w)\,p(w)}{p(D)}$$ $$\text{Therefore: } \log p(w \mid D) = \log p(D \mid w) + \log p(w) - \log p(D)$$ $$\text{Substitute: } \operatorname{KL} = \mathbb{E}_{q}[\log q] - \mathbb{E}_{q}[\log p(D \mid w) + \log p(w) - \log p(D)]$$ $$= \mathbb{E}_{q}[\log q] - \mathbb{E}_{q}[\log p(D \mid w)] - \mathbb{E}_{q}[\log p(w)] + \log p(D)$$ $$= (\mathbb{E}_{q}[\log q] - \mathbb{E}_{q}[\log p(w)]) - \mathbb{E}_{q}[\log p(D \mid w)] + \log p(D)$$
Step 3: Recognize the KL between $q$ and the prior
$$\mathbb{E}_{q}[\log q] - \mathbb{E}_{q}[\log p(w)] = \operatorname{KL}[q \parallel p(w)]$$ $$\operatorname{KL}[q \parallel p(w \mid D)] = \operatorname{KL}[q \parallel p(w)] - \mathbb{E}_{q}[\log p(D \mid w)] + \log p(D)$$
Step 4: Rearrange to isolate the ELBO
$$\operatorname{KL}[q \parallel p(w \mid D)] = \mathbb{E}_{q}[\log q] - \mathbb{E}_{q}[\log p(D \mid w)] - \mathbb{E}_{q}[\log p(w)] + \log p(D)$$ $$= (\mathbb{E}_{q}[\log q] - \mathbb{E}_{q}[\log p(w)]) - \mathbb{E}_{q}[\log p(D \mid w)] + \log p(D)$$ $$= \operatorname{KL}[q \parallel p(w)] - \mathbb{E}_{q}[\log p(D \mid w)] + \log p(D)$$ $$\operatorname{KL}[q \parallel p(w \mid D)] = -\bigl( \color{#1565c0}{\mathbb{E}_{q}[\log p(D \mid w)]} - \color{#e65100}{\operatorname{KL}[q \parallel p(w)]} \bigr) + \log p(D)$$ $$\boxed{\operatorname{ELBO}[q] = \color{#1565c0}{\mathbb{E}_{q}[\log p(D \mid w)]} - \color{#e65100}{\operatorname{KL}[q \parallel p(w)]}}$$ $$\operatorname{KL}[q \parallel p(w \mid D)] = -\operatorname{ELBO}[q] + \log p(D)$$
Final result: the ELBO
$$\boxed{\operatorname{ELBO}[q] = \underbrace{\color{#1565c0}{\mathbb{E}_{q}[\log p(D \mid w)]}}_{\text{data fit}} - \underbrace{\color{#e65100}{\operatorname{KL}[q \parallel p(w)]}}_{\text{regularization}}}$$

Derivation summary: Starting from $\operatorname{KL}[q \parallel p(w \mid D)]$, we expand the definition, apply Bayes' theorem, separate terms, and recognize that one group forms $\operatorname{KL}[q \parallel p(w)]$. Rearranging isolates the ELBO as the negative of the gap between $\operatorname{KL}[q \parallel p(w \mid D)]$ and $\log p(D)$.

Since $\operatorname{KL} \ge 0$, we have:

$$\operatorname{KL}[q \parallel p(w \mid D)] = -\operatorname{ELBO}[q] + \log p(D) \ge 0$$ $$\boxed{\operatorname{ELBO}[q] \le \log p(D)}$$

This is why it's called a lower bound: the ELBO is always less than or equal to the log-evidence log p(D). Maximizing the ELBO is equivalent to minimizing KL[q || p(w|D)].

Intuition: Two Competing Forces

$\operatorname{ELBO} = \text{Data Fit} - \operatorname{KL}[q \parallel \text{Prior}]$

The ELBO has two terms that pull in opposite directions:

  • $\mathbb{E}_{q}[\log p(D \mid w)]$ (data fit): push $q$ to put mass on weights that explain the data well. This is like the standard training loss.
  • $-\operatorname{KL}[q \parallel p(w)]$ (regularization): push $q$ to stay close to the prior. This prevents overfitting and keeps the weights from becoming too extreme.

Analogy: You're trying to guess a number. The data fit says "the answer is probably around 7, based on the evidence". The prior says "most numbers in this problem are between -3 and 3". The posterior balances these: it will be somewhere between, weighted by how much data you have.

Why Is It Called a "Lower Bound"?

The ELBO is a lower bound on the log-evidence $\log p(D)$ (also called the "log marginal likelihood"). Since $\operatorname{KL} \ge 0$:

$$\log p(D) \ge \operatorname{ELBO}[q]$$

The gap between the ELBO and $\log p(D)$ is exactly $\operatorname{KL}[q \parallel p(w \mid D)]$ — the quality of our approximation. If $q$ perfectly matches the posterior, the gap is zero.

How We Actually Compute It

In practice, we approximate the expectation using Monte Carlo sampling:

# Pseudo-code for ELBO computation in a BNN
def compute_elbo(model, q_dist, prior, x_batch, y_batch):
    # 1. Sample weights from the variational posterior
    w_sample = q_dist.sample()
    
    # 2. Forward pass with sampled weights
    predictions = model.forward(x_batch, w_sample)
    
    # 3. Data fit term: log-likelihood
    data_fit = log_likelihood(predictions, y_batch)
    
    # 4. KL term (closed-form for Gaussians)
    kl = kl_divergence(q_dist, prior)
    
    # 5. ELBO = data_fit - kl
    elbo = data_fit - kl / N  # N = number of mini-batches (unbiased estimate)
    return -elbo  # return negative for gradient descent
⚠️ Mini-batch scaling: In practice, we divide the KL by the number of mini-batches so that the total ELBO over one epoch is unbiased. This is not the same as "KL annealing" (which is a separate trick where you gradually increase the KL weight from 0 to 1 during training, often helpful because the data fit term dominates early on).
✅ You now understand the core of variational BNNs: Everything in variational inference revolves around maximizing the ELBO. The different methods (Bayes by Backprop, etc.) are different ways of specifying q, computing the KL, and estimating the expectation efficiently.
