Bayesian Neural Networks — For Beginners

🎯 In one sentence

A Bayesian neural network replaces the fixed weights of a standard neural network with probability distributions — so instead of one guess, you get a guess and a measure of how uncertain you should be.

You are a mathematician, so the good news is: you already understand 90% of what's needed. The rest is learning a bit of Python vocabulary and the specific way that Bayesian ideas get applied to neural networks. This page builds up from the absolute basics.

1. What is a Neural Network?

A neural network is just a function — a composition of simple linear transformations and simple nonlinearities — that we tune to fit data. That's it.

The Basic Building Block: A Linear Layer

The simplest piece is a linear layer, which is just an affine transformation:

Linear Layer
y = W x + b

Where:

  • W ∈ ℝm × n is the weight matrix (the parameters we tune)
  • b ∈ ℝm is the bias vector
  • x ∈ ℝn is the input
  • y ∈ ℝm is the output
🔍 For the mathematician: This is exactly an affine map between finite-dimensional vector spaces. If m = n = 1, it's the line y = wx + b from high school.

Activation Functions: Why We Need Nonlinearity

If we only stacked linear layers, the composition would still be linear — an affine map of an affine map is still affine. To learn interesting patterns, we need nonlinearity.

The most common nonlinearity is the ReLU (Rectified Linear Unit):

ReLU
ReLU(z) = max(0, z)

Think of ReLU as a "gate" that passes positive values through and blocks negative ones. Other common activation functions:

  • Sigmoid: σ(z) = 1 / (1 + e^{-z}) — squashes to (0, 1)
  • Tanh: tanh(z) — squashes to (-1, 1)

A Neural Network is a Composition

A 2-Layer Neural Network
f(x) = ReLU(W2 · ReLU(W1 x + b1) + b2)

Each intermediate vector is called a hidden layer. The "depth" is the number of layers. The dimensions of each layer are hyperparameters we choose.

Analogy: A neural network is like a long sequence of small matrix multiplications, each followed by a "gate" that zeros out negative values. The weights are dials — we turn them until the network produces the output we want.

2. A Neural Network in PyTorch (The Code)

Let's make this concrete. Here is a complete neural network in PyTorch for classifying handwritten digits (0-9) from 28×28 pixel images: 

import torch
import torch.nn as nn

# Define the network architecture
class MyNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer1 = nn.Linear(28*28, 128)   # W1: (128 × 784), b1: (128)
        self.layer2 = nn.Linear(128, 64)       # W2: (64 × 128), b2: (64)
        self.layer3 = nn.Linear(64, 10)        # W3: (10 × 64),  b3: (10)
        self.relu   = nn.ReLU()

    def forward(self, x):
        x = self.relu(self.layer1(x))   # → (batch, 128)
        x = self.relu(self.layer2(x))   # → (batch, 64)
        x = self.layer3(x)              # → (batch, 10) — no ReLU on last layer
        return x

# Create the network and test it
model = MyNetwork()
fake_images = torch.randn(32, 784)   # 32 random 28×28 images, flattened
output = model(fake_images)           # → 32 rows of 10 scores
print(output.shape)                   # → torch.Size([32, 10])
🔍 What just happened? We defined 3 weight matrices. nn.Linear creates W and b internally. The forward method chains them with ReLU nonlinearities. The output is 10 numbers per image — scores for "is this a 0?", "is this a 1?", etc.

The Training Loop

We need a loss function to measure how wrong the network is, and an optimizer to update the weights. The standard approach is gradient descent: 

optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
loss_fn   = nn.CrossEntropyLoss()

for images, labels in training_data:
    predictions = model(images)          # forward pass
    loss = loss_fn(predictions, labels)  # how wrong are we?
    
    optimizer.zero_grad()                # clear old gradients
    loss.backward()                      # compute gradients (backpropagation)
    optimizer.step()                     # update weights slightly

After many iterations, the weights converge to values that make the network accurate. This is a trained model.

3. The Problem: Standard NNs Don't Know What They Don't Know

⚠️ Key limitation: After training, the network gives you one answer per input. It doesn't distinguish between "I'm very sure this is a 7" and "I'm guessing this might be a 7". For high-stakes decisions, that's a serious issue.

Consider: you show the network a picture of a cat (something it was never trained on). It will still output 10 numbers summing to 1 (because of the softmax), and one of them will be the largest. It has to pick something. But it shouldn't be confident.

This is where Bayesian neural networks come in. Instead of learning a single best weight vector w, they learn a distribution over weights.

4. Bayesian Inference in One Slide

You know Bayes' theorem:

Bayes' Theorem
p(w | D) = p(D | w) p(w) / p(D)

In the context of neural networks:

  • Prior p(w) — what we believe about the weights before seeing data (e.g., "weights should be small")
  • Likelihood p(D | w) — how probable is the training data given a specific set of weights
  • Posterior p(w | D) — what we believe about the weights after seeing the data
  • Evidence p(D) — the normalizing constant (usually intractable)

Intuition: The posterior is a compromise between what we believed before (prior) and what the data tells us (likelihood). If the data is strong, the posterior is dominated by the likelihood. If the data is weak, the posterior stays close to the prior.

The key difficulty: p(D) involves an integral over all possible weights, which is exponentially large. So we never compute the exact posterior — we approximate it.

5. What Makes a Neural Network "Bayesian"?

In a standard neural network, training finds a point estimate wMAP (the Maximum A Posteriori weights). In a Bayesian neural network, we maintain a distribution q(w) over weights and use it to make predictions:

Predictive Distribution (BNN)
p(y | x, D) = ∫ p(y | x, w) q(w) dw

Instead of one forward pass, we sample many weight configurations from q(w) and average their predictions. The variance across these samples gives us the uncertainty estimate.

💡 Key insight: The predictive variance decomposes into aleatoric uncertainty (irreducible noise in the data) and epistemic uncertainty (reducible uncertainty from lack of knowledge). Epistemic uncertainty is high for inputs far from the training data — this is how the BNN says "I don't know."

6. How to Approximate the Posterior

Since the exact posterior is intractable, we need approximation methods. Here are the four main approaches, ordered by conceptual complexity:

Method 1: Monte Carlo Dropout

The simplest trick: keep dropout turned on at test time, and run multiple forward passes. Each pass uses a different random mask, giving a different prediction. The variance across passes is the uncertainty estimate.

✅ Why it works: Dropout during training can be interpreted as variational inference with a Bernoulli-distributed posterior. This was shown by Gal & Ghahramani (2016).

Method 2: Laplace Approximation

Train a standard network to find the MAP weights, then fit a Gaussian distribution around that optimum using the Hessian (matrix of second derivatives) of the loss.

Laplace Approximation
q(w) = 𝒩(w | wMAP, H−1)

Where H is the Hessian of the negative log-posterior at the MAP solution. See Daxberger et al. (2021) for modern best practices.

Method 3: Variational Inference (Bayes by Backprop)

Directly learn a distribution qθ(w) (typically Gaussian with diagonal covariance) by minimizing the KL divergence between q and the true posterior. This is equivalent to maximizing the ELBO (Evidence Lower Bound):

ELBO Objective
ℒ = 𝔼q[log p(D | w)] − KL[q(w) || p(w)]

The first term encourages fitting the data; the second term keeps the distribution close to the prior (regularization). See Blundell et al. (2015).

Method 4: Hamiltonian Monte Carlo (HMC)

The gold standard: directly sample from the exact posterior using gradient-guided MCMC. This gives the most accurate uncertainty estimates but is too expensive for large models. See Betancourt (2017) for an excellent introduction.

7. Quick Comparison

Method When does Bayes happen? Cost vs Standard NN Accuracy
MC Dropout Both (training + test) ≈ 1× training, T× test Surprisingly good
Laplace After training (post-hoc) ≈ 1× training + Hessian Good for last layer
Bayes by Backprop During training ≈ 2× slower, 2× params Good (Gaussian assumption)
HMC Special training procedure 100-1000× Gold standard (exact)
💡 Recommendation: Start with MC Dropout — it's the simplest thing that actually works. Move to Laplace if you need principled uncertainty with minimal code changes. Dive into VI (Bayes by Backprop) when you want learned uncertainty.
