What is a sequence?

A sequence of real numbers is a list \[x_1,x_2,x_3,\ldots, x_n, x_{n+1},\ldots\] We say a property holds for sufficiently large \(n\) if it holds after some index. More precisely, if there exists an index \(N\) such that the property holds for \(n \geq N\). For instance, we can have a sequence \(x_n\) written as \[1,2,3,5,1,2,3,0,0,0,0,0,\ldots\] which stays zero forever after some index. So, we have that this sequence \(x_n\) is \(0\) for sufficiently large \(n\).

Another example is the following. Imagine we have a sequence \(x_n\) that starts negative, but eventually becomes positive. We would say \(x_n\) is positive for sufficiently large \(n\).

Sometimes, a sequence \(x_n\) gets closer and closer to a unique value \(x\). Take for instance, \[x_n = \frac1n.\] As we increase \(n\), the value \(1/n\) gets closer to \(0\).

When this tendency happens, we say that the sequence is convergent. In this case, \(\frac1n\) converges to 0. We denote this phenomenon by \(\frac1n \to 0\). Note that similar behavior occurs with \(\frac1{n+1}\), \(\frac1{2n+1}\), \(\frac1{n^2+1}\), and so on. They all converge to \(0\).

The sequence I previously described, which becomes constant after some index, is also convergent. So, if \(x_n = x\) for \(n\) sufficiently large, then \(x_n \to x\).

The value \(x\) to which a sequence \(x_n\) converges is called the limit of \(x_n\) and it is common to denote this number by \(\lim_n x_n\). So, we have \(\lim_n \frac1n= 0\) and for \(x_n\) constant and equal to \(x\) for \(n\) sufficiently large we have \(\lim_n x_n = x\).

Not all sequences have this behavior, take for instance \(x_n = (-1)^{n+1}\). \[1,-1,1,-1,1,-1,\ldots\] This sequence does not converge to a unique value, it oscillates between 1 and -1.

Let me sketch a definition of convergence so we can stop being so vague. Consider once again \(\frac 1n\). We want to give a formal argument that \(\frac 1n\) converges to \(0\). Let us collect a bit of evidence of this phenomenon.

  1. For \(n> 2\) we have \(0<\frac 1n< \frac 12 = 0.5\),
  2. for \(n>3\) we have \(0<\frac 1n< \frac 13 = 0.333\ldots\),
  3. for \(n>4\) we have \(0<\frac 1n< \frac 14 = 0.25\),
  4. for \(n>5\) we have \(0<\frac 1n< \frac 15 = 0.20\),
  5. \(\ldots\)

So, given a number \(r>0\) we expect that \(0<\frac 1n<r\) for \(n\) sufficiently large. In fact, if we take \(n>r^{-1}\) we have \(0<\frac1n<r\).

So, no matter how close we want to trap \(\frac 1n\) to 0, we can do it with \(n\) sufficiently large.

Definition: We say \(x_n\) converges to \(x\) if \[ r>0 \quad \Longrightarrow \quad x-r<x_n<x+r \quad \text{for } n\text{ sufficiently large}.\] In the case of \(x_n = (-1)^{n+1}\), if we assume that this sequence converges to a point \(x\), then for \(r=0.1\) we must have \[x - 0.1<x_n<x+0.1 \quad \text{for }n\text{ sufficiently large}.\] For \(n\) odd, we get \(x-0.1 <1<x+0.1\), which means \(0.9<x<1.1\). For \(n\) even, \(x-0.1 < -1< x+0.1\), which means \(-1.1<x<-0.9\). So, if \(x_n\) were to have limit \(x\), we would have \(x\) positive and negative at the same time, which makes no sense. So, \(x_n\) is not convergent.

Example

\[x_n = \frac{n}{n+1} \to 1.\]

Note that the data shows a tendency towards 1. To see that this is the case, rewrite \(x_n\) as \[x_n = 1-\frac1{n+1}.\] As we already observed, the \(\frac1{n+1}\) converges to 0. Thus, \(x_n \to 1\). More formally, given an arbitrary \(r>0\) we have \[\frac n{n+1} = 1-\frac 1{n+1},\] which is smaller than \(1\) and thus smaller than \(1+r\), and \[\frac n{n+1} = 1-\frac 1{n+1} >1-r\] for \(n+1>r^{-1}\). Thus, \[1-r<\frac n{n+1} < 1+r\] for sufficiently large \(n\).

Example

\[x_n = a^n \to 0 \quad \text{for} \quad 0<a<1.\] This one is a bit tricky and we will need a special inequality. Observe that \(a\) can be written as \(1/(1+h)\) with \(h = a^{-1}-1>0\). Now, by the binomial formula \[(1+h)^n = {{n}\choose{0}}+{{n}\choose{1}}h+{{n}\choose{2}}h^2+\cdots\] we get this neat inequality \[(1+h)^n \geq 1+nh.\] So, we obtain \[a^n = \frac1{(1+h)^n} \leq \frac1{1+nh} \to 0.\] and we conclude that \[a^n \to 0.\] The formal definition is also satisfied: given \(r>0\) we have \[-r<a^n< r\] for \(nh+1>r^{-1}\), meaning it holds for sufficiently large \(n\).

This inequality used above is a particular case of the Bernoulli inequality.

Theorem: (Bernoulli inequality) If \(x>-1\) and \(n \geq 1\), then \((1+x)^n \geq 1+nx\).

Proof:

Proof by induction. It is true for \(n=1\). Assume it is true for \(n\). \[(1+x)^{n+1} = (1+x)(1+x)^{n} \geq (1+x) (1+nx) = 1+(n+1)x+nx^2 \geq 1+(n+1)x.\] QED

Corollary: If \(x>-1\) and \(n \geq 1\), then \((1+x)^{\frac 1n} \leq 1+\frac xn\).

Proof:

From Bernoulli inequality \[\left(1+\frac xn\right)^n \geq 1+x,\] \[1+\frac xn \geq (1+x)^{\frac 1n}.\] QED

Example

\[\frac{5^n}{n!} \to 0.\] Let us first verify that \(5^n < n!\) for sufficiently large \(n\). By the table, we suspect that \(n\geq 12\) is sufficiently large. Let's prove that by induction. For \(n=12\) the result is true. Assume that \(5^n < n!\) for some \(n\geq12\). We have \[(n+1)! = (n+1) n! > 5 n! > 5 \times 5^n = 5^{n+1}.\]Therefore, \(5^n < n!\) is true for \(n\geq 12\). From here we can show that \(\frac {5^n}{n!} \to 0\). Just note that for \(n>12\) \[\frac{5^n}{n!} = \frac{5^{12}}{12!} \frac{5}{13}\frac{5}{14} \cdots \frac 5{n}.\] Since \(5^{12}<12!\) and \(\frac{5}{13},\frac{5}{14}, \ldots, \frac{5}{n}<\frac12\) we get \[\frac{5^n}{n!} < \frac1{2^{n-12}} = \frac{2^{12}}{2^n} \to 0.\] Therefore, \(\frac {5^n}{n!} \to 0\).

In fact, \(5\) is not special at all.

Example

\[\frac{a^n}{n!} \to 0 \quad \text{for } a>0.\] Fix a positive integer \(m\) satisfying \(m>2a\). Define \(c=a^m/m!\). For \(k\geq 1\) we have \[\frac{a^{k+m}}{(k+m)!} = \frac{a^m}{m!} \frac {a}{1+m}\frac {a}{2+m} \cdots \frac {a}{k+m} < c \left(\frac 12\right)^k,\] where we used that \(1+m,2+m, \ldots, k+m >2a\). Thus, writing \(n=k+m\) we get \[\frac{a^{n}}{n!}< \frac{c}{2^{k}} = \frac{c}{2^{n-m}} = \frac{2^m c}{2^n} \to 0.\]

Basic Properties

Let us discuss some basic properties before doing more examples.

Theorem: If \(x_n \to x\) and \(y_n \to y\), then \(x_n+y_n \to x + y\).

Proof:

Note that \[|x_n+y_n-(x+y)| \leq |x_n-x|+|y_n-y|.\]Fix \(r>0\). For \(n\) sufficiently large we have \[|x_n-x|<\frac r2 \quad \text{and}\quad |y_n-y| < \frac r2\] and it follows \[|(x_n+y_n) - (x+y)| \leq |x_n-x|+|y_n-y|<r.\] QED

For instance, the sequence \(2^{\frac1n} + \frac n{n+1} \to 2\). Another example, \[\frac{2(n-1)^3-\frac1n}{n^3} = \frac{2(n^3-3n^2+3n-1)}{n^3}-\frac{1}{n^4} =2-\frac{6}{n}+ \frac{6}{n^2}-\frac{2}{n^3} -\frac{1}{n^4} \to 2.\]

Theorem. If \(x_n \to 0\) and \(y_n\) is bounded, then \(x_ny_n \to 0\).

Proof:

There exists \(M>0\) such that \(|y_n|\leq M\) and, as a consequence, \[|x_n y_n| \leq M |x_n| \to 0.\] QED

A good example of this property is \(\frac{\sin(n)}n \to 0\). The sine function is bounded and, because of that, the \(\frac 1n\) dominates the convergence.

Theorem: If \(x_n \to x\), then \(x_n\) is bounded.

Just imagine a sequence converging towards \(x\), for \(n\) sufficiently large we must have \(x_n\) close to \(x\). The sequence \(x_n\) might start far away from \(x\), but eventually it must get very close.

Proof:

The definition of convergence holds for any \(r>0\), in particular \(r=1\):\[x-1<x_n<x+1 \quad \text{for } n \text{ sufficiently large}.\] As a consequence, we get \[−|𝑥| −1 <𝑥_𝑛 <|𝑥| +1 \quad \text{for } n \text{ sufficiently large}.\] Therefore, \[|𝑥_𝑛| <|𝑥| +1 \quad \text{for } n \text{ sufficiently large}.\]Meaning that there exists \(𝑁\) such that \[|𝑥_𝑛|<|𝑥|+1 \quad \text{for } 𝑛≥𝑁.\] In particular, taking \(M\) larger than \(1+|𝑥|,|𝑥_1|,…,|𝑥_𝑁|\) we get \[|𝑥_n|≤M \quad \text{for every }n\] and we conclude \(x_n\) is bounded. QED

Theorem: If \(x_n \to x\) and \(y_n \to y\), then \(x_ny_n \to xy\).

Proof:

We write \[x_ny_n - xy = (x_n-x)y_n + x(y_n-y)\] and use that \(|y_n|\leq M\) for some \(M>0\), since convergent sequences are bounded. We obtain \[|x_ny_n - xy| \leq M|x_n-x|+|x||y_n-y| \to 0.\] QED

Theorem . If \(u_n \to u\), \(v_n \to v\), and \(v \neq 0\), then \(v_n\) is non-zero for sufficiently large \(n\) and the expression \(\frac{u_n}{v_n}\) makes sense. Additionally, \[\frac{u_n}{v_n} \to \frac uv.\]

Proof:

Let us prove first that \(v_n\) is non-zero for sufficiently large \(n\). By definition of limit, we have \[v-r \leq v_n \leq v + r \quad \text{for sufficiently large }n\] for any \(r>0\). Taking \(r = \frac{|v|}2\) we get \[v-\frac{|v|}2<v_n < v+\frac{|v|}2\quad \text{for sufficiently large }n.\] If \(v>0\), then we get \(v_n > \frac {|v|}2>0\). If \(v<0\), then we get \(v_n < -\frac{|v|}2<0\). Now using \(|v_n|> |v|/2\) we obtain \[\left|\frac{1}{v_n} - \frac 1v \right| = \frac{|v_n-v|}{|v_n||v|} \leq \frac{|v_n-v|}{|v|^2/2} \to 0.\] Therefore, \[\frac1{v_n} \to \frac1{v}.\] Combining this with the preceding theorem on products, we reach the result. \[\frac{u_n}{v_n} \to \frac u{v}.\] QED

Example

\[\frac{2n^{11}+23 n^3 +\sin(n)}{n^{11}+n-1} \to 2\] Just write \[\frac{2n^{11}+23 n^3 +\sin(n)}{n^{11}+n-1} = \frac{2+ \frac{23}{n^8} +\frac{\sin(n)}{n^{11}}}{1+\frac1{n^{10}}-\frac{1}{n^{11}}}\] Since \[2+ \frac{23}{n^8} +\frac{\sin(n)}{n^{11}} \to 2\] and \[1+\frac1{n^{10}}-\frac{1}{n^{11}} \to 1\] we get \[\frac{2n^{11}+23 n^3 +\sin(n)}{n^{11}+n-1} \to 2.\]

It is not hard to see, by the same argument as above, that if \(p(x)\) and \(q(x)\) are non-zero polynomials, then \[\lim_n \frac{p(n)}{q(n)} = 0\]when \[\deg p < \deg q.\]This is the case for \[\frac{2n^2-3}{32 n^3 +2} \to 0.\]

If \(\deg p = \deg q\), then the limit is \(\frac ab\) where \(a\) and \(b\) are the leading coefficients of \(p\) and \(q\). For the reader not familiar with anatomy of polynomials, leading coefficient of a polynomial is the coefficient of the monomial of highest degree. For instance, the leading coefficient of \(2 x^2 +1\) is \(2\). The leading coefficient of \(x^{10}-x+1\) is \(1\). From here we get, \[\frac{31 n^3+23n}{21 n^3+12n^2} \to \frac{31}{21}.\]
