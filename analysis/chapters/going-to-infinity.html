Going to infinity

Definition: We say xnx_n diverges to ∞\infty if r>0⇒xn>rfor n sufficiently large. r>0 \quad \Longrightarrow \quad x_n>r \quad \text{for } n\text{ sufficiently large}. We write xn→∞x_n \to \infty or limn→∞xn=∞\lim\limits_{n \to \infty} x_n = \infty.

We say xnx_n diverges to −∞-\infty if −xn→∞-x_n \to \infty. Of course, we write xn→−∞x_n \to -\infty or limn→∞xn=−∞\lim\limits_{n \to \infty} x_n = -\infty.

The most obvious example is xn=nx_n= n, since for every r>0r>0 we have n>rn>r for nn sufficiently large.

Theorem: If xn>0x_n>0 and xn→0x_n \to 0, then 1xn→∞\frac 1{x_n} \to \infty.

Proof:
