Exponentials

Now we discuss exponentials \(y=a^x\), where \(a>0\).

All these curves pass through \((0,1)\) because \(a^0=1\). For \(a>1\) the function is increasing, and for \(0<a<1\) it is decreasing. For \(a=1\) it is constant.

At \((0,1)\) we can draw a tangent line \(y=1+kx\). For \(a>1\), the slope \(k\) is positive, and for \(0<a<1\), the slope \(k\) is negative. In both cases, the curve is on or above the line: \[a^x\geq 1+kx.\]

When \(u\) is very small, \(a^u\simeq 1+ku\). For any fixed \(x\) and very large \(n\), \(u = \frac x n\) is close to \(0\) and \[a^{x/n}\simeq 1+\frac{kx}{n}, \qquad a^x\simeq\left(1+\frac{kx}{n}\right)^n.\] This leads to the following conjecture: \[\left(1+\frac{kx}{n}\right)^n\to a^x.\]

Theorem: For every real \(x\), \[\left(1+\frac{kx}{n}\right)^n\to a^x.\]

Proof:

Assume \(a>1\). The slope \(k\) must be positive. Also, we can always assume \(n\) is sufficiently large and, as a consequence, we can assume \(1+\frac{kx}n>0\).

Since \[a^{x/n}\geq 1+\frac{kx}{n},\] we get \[\left(1+\frac{kx}{n}\right)^n\leq a^x.\]

Now, observe that \[a^{-y/n}\geq 1-\frac{ky}{n},\] and \[a^{y/n}\leq\frac{1}{1-ky/n} =1+\frac{ky/n}{1-ky/n},\]where we can assume \(1-ky/n>0\) for sufficiently large \(n\). Write \[\frac{kx}{n}=\frac{ky/n}{1-ky/n}.\] We get \[x-\frac{kxy}{n}=y, \qquad y=\frac{nx}{n+kx}.\] Therefore,

\[a^{y/n}\leq1+\frac{ky/n}{1-ky/n},\]

\[a^{\frac{x}{n+kx}}\leq 1+\frac{kx}{n},\]

\[a^{\frac{nx}{n+kx}}\leq \left(1+\frac{kx}{n}\right)^n.\] We obtain the inequalities \[a^{\frac{nx}{n+kx}}\leq \left(1+\frac{kx}{n}\right)^n \leq a^x.\] Now, \[\frac{nx}{n+kx} = x - \frac{kx^2}{n+kx}\] and \[a^{\frac{nx}{n+kx}} = a^x a^{-\frac{kx^2}{n+kx}}.\]

Because \(1- \frac{k^2x^2}{n+kx}\leq a^{-\frac{kx^2}{n+kx}}\), we have the inequality \[a^x\left(1- \frac{k^2x^2}{n+kx}\right)\leq \left(1+\frac{kx}{n}\right)^n \leq a^x\] Therefore, \[\left(1+\frac{kx}{n}\right)^n \to a^x.\] For \(a=1\), we have \(k=0\) and the result is automatically true.

For \(0<a<1\), write \(b=1/a>1\).

Reflecting the graph \(y=a^x\) across the \(y\)-axis, by \((x,y)\mapsto(-x,y)\), gives \(y=a^{-x}\). The same reflection sends the tangent line \(y=1+kx\) to \(y=1-kx\). Thus, for \(b=1/a\), the tangent slope of \(y=b^x\) at \((0,1)\) is \(-k\). Applying the result above to \(b\) and \(-x\), we get \[\left(1+\frac{(-k)(-x)}{n}\right)^n\to b^{-x}=a^x.\] So the result holds for every \(a>0\). QED

The result links \(a>0\) and \(k\), the slope of \(a^x\) at \(x=0\). A natural question is: which base \(a\) gives slope \(k=1\)? This number is called Euler’s number and is denoted by \(e\). Its value is \(2.71828\ldots\) and is one of the most important constants in Mathematics. Since we can write \[\left(1+\frac 1n\right)^n \to e\] we can estimate \(e\).
