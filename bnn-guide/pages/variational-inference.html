7. Variational Inference — Bayes by Backprop

🎯 In one sentence

Instead of finding the best single weight value, learn a Gaussian distribution for each weight (mean and standard deviation) by maximizing the ELBO using backpropagation and the reparameterization trick.

This is among the most mathematically principled of the practical BNN methods (though HMC, page 10, is more principled still — it samples from the exact posterior rather than approximating it with a Gaussian family). This method is also known as Bayes by Backprop (Blundell et al., 2015).

The Key Idea

In a normal neural network, each weight w is a single number. In Bayes by Backprop:

Each weight has two parameters
w = μ + σ ⊙ ε, where ε ~ N(0, 1)

μ: the mean (best guess for the weight)
σ: the standard deviation (how uncertain we are)
ε: random noise (sampled fresh each forward pass)

The reparameterization trick is what makes this work. By writing w = μ + σε, we separate the randomness (ε) from the parameters (μ, σ). This lets gradients flow through the sampling step during backpropagation.

The Mathematics

We want to maximize the ELBO with respect to the variational parameters (μ, σ for each weight):

Objective to maximize
ELBO = Eq[log p(D|w)] - KL[q || p(w)]

The KL term can be computed in closed form when both q and the prior p are Gaussian:

KL between two Gaussians
KL[ N(μq, σq²) || N(μp, σp²) ] = log(σp/σq) + (σq² + (μq - μp)²) / (2σp²) - ½

The data term is approximated by a single Monte Carlo sample (one forward pass with sampled weights).

Practical Implementation Details

  • σ parameterization: We don't optimize σ directly (it must be positive). Instead, we optimize ρ where σ = log(1 + exp(ρ)) (softplus). This lets us use unconstrained optimization.
  • KL scaling: The KL is divided by the number of mini-batches for unbiased mini-batch training.
  • Prior: Often a scale mixture of two Gaussians (one narrow, one wide) works better than a single Gaussian.
  • Local reparameterization: Instead of sampling each weight independently, sample the pre-activation (the weighted sum) — this reduces gradient variance.

Complete PyTorch Implementation

Here is a full implementation of a Bayesian linear layer using Bayes by Backprop:

import torch
import torch.nn as nn
import torch.nn.functional as F
import math

# ---------- Bayesian Linear Layer ----------
class BayesianLinear(nn.Module):
    def __init__(self, in_features, out_features,
                 prior_sigma_1=1.5, prior_sigma_2=0.1, prior_pi=0.5):
        super().__init__()
        self.in_features  = in_features
        self.out_features = out_features
        
        # Variational parameters: mean and rho (for std)
        self.w_mu    = nn.Parameter(torch.randn(out_features, in_features) * 0.1)
        self.w_rho   = nn.Parameter(torch.randn(out_features, in_features) * 0.1)
        self.b_mu    = nn.Parameter(torch.randn(out_features) * 0.1)
        self.b_rho   = nn.Parameter(torch.randn(out_features) * 0.1)
        
        # Prior parameters (scale mixture of Gaussians)
        self.prior_sigma_1 = prior_sigma_1
        self.prior_sigma_2 = prior_sigma_2
        self.prior_pi      = prior_pi
        
        # Store for KL computation
        self.kl_loss = 0.0
    
    # Compute std from rho (softplus ensures positivity)
    def _std(self, rho):
        return torch.log(1 + torch.exp(rho))  # softplus
    
    # Prior log-probability (scale mixture of two Gaussians)
    def _log_prior(self, w):
        def log_gauss(w, sigma):
            return -0.5 * (w**2 / sigma**2 + math.log(2*math.pi) + 2*math.log(sigma))
        log_p1 = log_gauss(w, self.prior_sigma_1)
        log_p2 = log_gauss(w, self.prior_sigma_2)
        return torch.log(self.prior_pi * torch.exp(log_p1) +
                       (1 - self.prior_pi) * torch.exp(log_p2))
    
    # Variational posterior log-probability (Gaussian)
    def _log_q(self, w, mu, rho):
        sigma = self._std(rho)
        return -0.5 * ((w - mu)**2 / sigma**2 +
                       math.log(2*math.pi) + 2*torch.log(sigma))
    
    # Forward pass with sampling
    def forward(self, x):
        # Sample noise
        eps_w = torch.randn_like(self.w_mu)
        eps_b = torch.randn_like(self.b_mu)
        
        # Reparameterization trick: w = mu + sigma * eps
        w = self.w_mu + self._std(self.w_rho) * eps_w
        b = self.b_mu + self._std(self.b_rho) * eps_b
        
        # Compute KL divergence for this layer
        # This is a SINGLE-SAMPLE Monte Carlo estimate of KL[q || prior].
        # The exact KL requires an intractable integral; we approximate it by
        # drawing one sample w ~ q and computing log q(w) - log prior(w).
        # This is unbiased (E[log q - log prior] = KL[q || prior]) but noisy.
        # Thanks to the reparameterization trick (w = mu + sigma * eps),
        # the gradient of this estimate w.r.t. mu and rho is unbiased.
        log_q    = self._log_q(w, self.w_mu, self.w_rho).sum()
        log_prior = self._log_prior(w).sum()
        log_q    += self._log_q(b, self.b_mu, self.b_rho).sum()
        log_prior += self._log_prior(b).sum()
        # kl_loss = log_q - log_prior  is a Monte Carlo estimate of KL[q || prior]
        self.kl_loss = log_q - log_prior
        
        # Linear transformation with sampled weights
        return F.linear(x, w, b)


# ---------- Full Bayesian Model ----------
class BayesianNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = BayesianLinear(784, 128)
        self.fc2 = BayesianLinear(128, 64)
        self.fc3 = BayesianLinear(64, 10)
    
    def forward(self, x, compute_kl=True):
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        x = self.fc3(x)
        
        # Sum KL from all layers
        if compute_kl:
            self.kl = self.fc1.kl_loss + self.fc2.kl_loss + self.fc3.kl_loss
        return x


# ---------- Training ----------
model = BayesianNN()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
num_batches = 100  # total mini-batches per epoch

for x_batch, y_batch in dataloader:
    pred = model(x_batch)
    
    # Negative log-likelihood (data fit term)
    nll = F.cross_entropy(pred, y_batch)
    
    # ELBO = - (NLL + KL / num_batches)
    loss = nll + model.kl / num_batches
    
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()


# ---------- Prediction with Uncertainty ----------
model.train()  # keep sampling active
predictions = []
for _ in range(50):   # 50 Monte Carlo samples
    pred = model(x_test, compute_kl=False)
    predictions.append(F.softmax(pred, dim=1))

predictions = torch.stack(predictions)  # (50, batch, 10)
mean = predictions.mean(dim=0)           # average prediction
var  = predictions.var(dim=0)           # uncertainty estimate

Pros and Cons

✅ Advantages❌ Disadvantages
Principled variational objective (ELBO) 2× parameters (μ and σ per weight)
Provides full weight distributions Gaussian posterior assumption is restrictive
Works with standard backpropagation Gradient variance can be high
Captures both aleatoric and epistemic uncertainty Tends to be overconfident (mode-seeking KL)
🔗 Where to go next: This method is the foundation of modern VI for BNNs. The MC Dropout method is simpler but less principled. Laplace approximation is another approach that's much cheaper (post-hoc) but only gives local uncertainty.
