9. Laplace Approximation

🎯 In one sentence

After normal training (finding the best single weight value), fit a Gaussian distribution around that optimum using a second-order Taylor expansion — the curvature of the loss landscape tells us how uncertain we should be.

⏰ When does the Bayesian part happen? Training vs. Inference

Laplace is the most "post-hoc" of all the methods. Compare:

MethodTrainingInference (test time)
Bayes by Backprop Learns a distribution (μ, σ) for each weight — training itself is Bayesian Sample from the learned distribution, average predictions
MC Dropout Standard training with dropout + L2 — secretly = ELBO Keep dropout on, run T forward passes, average
Laplace Completely standard MAP training — no Bayesian component at all After training: compute Hessian, fit Gaussian, sample — purely post-hoc

This means you can take any already-trained model and add uncertainty to it via Laplace. You don't need to retrain. That's the main selling point.

The Laplace approximation is the oldest Bayesian approximation (Laplace, 1774!). It was revived for modern deep learning by Daxberger et al. (2021) in "Laplace Redux". The beauty: it's a post-hoc method — train normally, then add uncertainty.

The Mathematics

We start with a MAP estimate of the weights (just normal training with weight decay).

The log-posterior around the MAP estimate wMAP can be approximated by a second-order Taylor expansion:

Second-order expansion of log-posterior
$$\log p(w \mid D) \approx \log p(w_{\text{MAP}} \mid D) - \frac{1}{2} (w - w_{\text{MAP}})^T H\,(w - w_{\text{MAP}})$$

The first-order term vanishes because we're at a maximum (gradient = 0). H is the Hessian matrix — the matrix of second derivatives of the negative log-posterior at the MAP estimate.

This expansion implies a Gaussian posterior approximation:

Laplace Approximation
$$p(w \mid D) \approx \mathcal{N}(w;\, w_{\text{MAP}}, H^{-1})$$

The posterior covariance is the inverse Hessian. The intuition: where the loss landscape is steep (high curvature), we're more certain (small variance). Where it's flat (low curvature), we're less certain (large variance).

The Problem: The Hessian is Huge

For a network with D parameters (millions), the Hessian is D × D. Storing it explicitly is impossible. We need approximations.

ApproximationMemoryQuality
Full HessianO(D²)Best (only for tiny models)
Kronecker-Factored (K-FAC)O(L · (d_in² + d_out²))Very good
DiagonalO(D)Moderate (ignores correlations)
Last-layer onlyO(L_out²)Surprisingly effective
💡 Last-layer Laplace is the sweet spot for practitioners. Treat the network as a fixed feature extractor (use all layers except the last as a black box), and only apply Laplace to the final linear layer. This is cheap and often gives excellent uncertainty estimates. The Laplace library makes this easy.

PyTorch Implementation (from scratch)

Here's a minimal Laplace approximation for the last layer of a classifier.

import torch
import torch.nn as nn
import torch.nn.functional as F

# ---------- Step 1: Train a normal network ----------
class FeatureExtractor(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Linear(784, 256), nn.ReLU(),
            nn.Linear(256, 128), nn.ReLU(),
        )
        self.classifier = nn.Linear(128, 10)  # last layer
    
    def forward(self, x):
        x = self.features(x)
        x = self.classifier(x)
        return x

model = FeatureExtractor()
# ... train normally (same as any classifier) ...

# ---------- Step 2: Laplace approximation on last layer ----------
# Extract features for all training data
model.eval()
features_list = []
with torch.no_grad():
    for x, y in train_loader:
        feats = model.features(x)
        features_list.append(feats)
        
features = torch.cat(features_list)      # (N, 128)
labels   = torch.cat([y for _, y in train_loader])  # (N,)

# Get last-layer weights (W, b)
W = model.classifier.weight  # (10, 128)
b = model.classifier.bias    # (10,)

# Compute the Hessian of the last layer (using the generalized Gauss-Newton, GGN)
# For classification with cross-entropy loss, the GGN approximation to the Hessian is:
#   H ≈ 1/N Σ_i J_i^T H_i J_i + prior_precision * I
# where J_i is the Jacobian of the logits w.r.t. weights, and H_i is the Hessian of
# the loss w.r.t. logits. For cross-entropy with softmax, H_i = diag(p_i) - p_i p_i^T.
# For binary/multi-class, this simplifies to p_i(1-p_i) for the diagonal of H_i
# (the "variance of the Bernoulli" at the output). Hence:
#   H ≈ Σ_i [p_i(1-p_i)] * φ_i φ_i^T
# where φ_i are the features and p_i is the predicted probability for class c.

logits = model.classifier(features)
probs  = F.softmax(logits, dim=1)

# Build Hessian (diagonal approximation for simplicity)
H_diag = torch.zeros_like(W)  # (10, 128)
for c in range(10):  # for each class
    p = probs[:, c]           # (N,) probability of class c
    weight = p * (1 - p)      # variance of Bernoulli
    # H_cc = Σ_i weight_i * φ_i φ_i^T  (diagonal: φ_i²)
    H_diag[c] = (features.T * weight).sum(dim=1) / features.shape[0]

# Posterior covariance is inverse Hessian
prior_precision = 1.0          # = 1/σ2_prior (this is a precision, NOT a variance!)
posterior_cov = 1.0 / (H_diag + prior_precision)  # (10, 128) diagonal

# ---------- Step 3: Predict with Uncertainty ----------
def predict_with_uncertainty(model, x, T=50):
    feats = model.features(x)   # (batch, 128)
    samples = []
    for _ in range(T):
        # Sample last-layer weights from posterior
        W_sample = W + torch.randn_like(W) * torch.sqrt(posterior_cov)
        # Bias posterior (same prior precision as weights)
        b_precision = prior_precision
        b_posterior_cov = 1.0 / (b_precision + features.shape[0] * probs.mean(dim=0).mean())
        b_sample = b + torch.randn_like(b) * torch.sqrt(b_posterior_cov)
        logits = F.linear(feats, W_sample, b_sample)
        samples.append(F.softmax(logits, dim=1))
    
    samples = torch.stack(samples)
    return samples.mean(dim=0), samples.var(dim=0)
⚠️ Note: This is a simplified implementation for illustration. In practice, use the Laplace library which handles K-FAC approximations, Hessian computation, and predictive distributions correctly. The key insight is that the curvature of the loss provides uncertainty information.
