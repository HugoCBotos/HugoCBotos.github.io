1. What is a Neural Network?

🎯 In one sentence

A neural network is just a function — a composition of simple linear transformations and simple nonlinearities — that we tune to fit data.

If you know linear algebra and calculus, you already know 90% of what a neural network is. The rest is just vocabulary and engineering.

The Basic Building Block: A Linear Layer

The simplest piece of a neural network is a linear layer. It takes an input vector $x \in \mathbb{R}^{n}$ and produces an output vector $y \in \mathbb{R}^{m}$:

Linear Layer
y = W x + b

Where:

  • W ∈ ℝm × n is the weight matrix (the "knobs" we tune)
  • b ∈ ℝm is the bias vector (an offset)

That's it. It's just matrix multiplication plus a constant. If m = 1 and n = 1, this is the familiar y = wx + b from high school.

🔍 For the mathematician: A linear layer is an affine transformation from ℝn to ℝm. The weights W define a linear map; the bias b translates it.

Activation Functions: Why We Need Nonlinearity

If we only stacked linear layers, the whole network would still be linear — a composition of affine maps is still affine. That's boring. To learn interesting patterns, we need nonlinearity.

After each linear layer, we apply a simple nonlinear function. The most common is ReLU:

ReLU (Rectified Linear Unit)
ReLU(z) = max(0, z)

Other common ones:

  • Sigmoid: σ(z) = 1 / (1 + e^{-z}) — squashes to (0, 1)
  • Tanh: tanh(z) = (e^{z} - e^{-z}) / (e^{z} + e^{-z}) — squashes to (-1, 1)

Putting It Together: A Neural Network

A neural network is just a composition of alternating linear layers and nonlinearities:

A 2-Layer Neural Network
f(x) = ReLU(W2 · ReLU(W1 x + b1) + b2)

The "depth" is the number of layers. A "deep" network has many layers. Each intermediate vector is called a hidden layer. The numbers of neurons (dimensions) in each layer are hyperparameters we choose.

Analogy: Think of a neural network as a very long sequence of small matrix operations, each followed by a "gate" that clips negative values to zero (ReLU). The weights are the dials — we turn them until the network produces the output we want.

Code: A Neural Network in PyTorch

Here is a complete, minimal neural network for classifying the digits 0-9 from 28×28 images:

import torch
import torch.nn as nn

# Define the network architecture
class MyNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer1 = nn.Linear(28*28, 128)   # W1: (128 × 784), b1: (128)
        self.layer2 = nn.Linear(128, 64)       # W2: (64 × 128), b2: (64)
        self.layer3 = nn.Linear(64, 10)        # W3: (10 × 64),  b3: (10)
        self.relu   = nn.ReLU()

    def forward(self, x):
        # x shape: (batch_size, 784) — a batch of flattened images
        x = self.relu(self.layer1(x))   # → (batch, 128)
        x = self.relu(self.layer2(x))   # → (batch, 64)
        x = self.layer3(x)              # → (batch, 10) — no ReLU on last layer
        return x

# Create the network
model = MyNetwork()

# Test it with random data
fake_images = torch.randn(32, 784)   # 32 random images
output = model(fake_images)           # → 32 rows of 10 numbers (scores for each digit)
print(output.shape)                   # → torch.Size([32, 10])
🔍 What just happened? We defined 3 weight matrices. Each nn.Linear creates a matrix W and a bias b internally. The forward method chains them together with ReLU nonlinearities. The output is 10 numbers per image — scores for "is this a 0?", "is this a 1?", etc.

How Training Works (The Short Version)

We have a loss function that measures how wrong the network's outputs are. The most common is cross-entropy loss for classification or mean squared error for regression.

Training uses gradient descent: compute the gradient of the loss with respect to every weight (this is called backpropagation), then nudge the weights slightly in the direction that reduces the loss. 

# Training loop (conceptual)
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
loss_fn   = nn.CrossEntropyLoss()

for images, labels in training_data:
    predictions = model(images)          # forward pass
    loss = loss_fn(predictions, labels)  # how wrong are we?
    
    optimizer.zero_grad()                # clear old gradients
    loss.backward()                      # compute gradients (backpropagation)
    optimizer.step()                     # update weights slightly

After many iterations, the weights converge to values that make the network accurate. This is the trained model.

The Problem: Neural Networks Don't Know What They Don't Know

⚠️ Key issue: After training, the network gives you one answer per input. It doesn't tell you "I'm very sure this is a 7" vs "I'm guessing this might be a 7". For high-stakes decisions, that's a serious limitation.

A Bayesian neural network fixes this by replacing the fixed weights with distributions. That's what the rest of this guide is about.
